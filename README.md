# Silicon Swell

**Big money. Tiny you.**

A playful editorial webpage about the money behind AI. Recognizable technology figures surf investment waves; visitors scroll through the scale, then add themselves to the picture.

Primary editorial takeaway: **“The scale of AI investment is almost impossible to comprehend.”**

Primary audience: **a broad public with no finance or AI knowledge**.

Voice: **sharper satire** — “Lovely day for a swim. Shame they bought the ocean.”

Working name: **Silicon Swell**. Repository name remains `rich-people-surfing`.

## Current status

Planning only, dated **22 October 2026**. This repository contains the refined concept, research, and implementation brief. There is no application scaffold, dependency installation, generated artwork, or local server yet.

The requested implementation will be a **static Vue 3 + Vite + TypeScript app with GSAP**, developed locally and self-hosted by the owner. No database, backend, accounts, or ChatGPT Sites deployment.
